# 评审 0007 — CLI 与本地控制台

| 项目 | 内容 |
| --- | --- |
| 提交 | `feat(app): add CLI and local control console` |
| 评审人 | 主导开发（自评） |
| 范围 | `src/cli.ts`、`src/cli/`、`src/ui/`、`test/ui.test.ts` |
| 结论 | 通过 |

## 检查清单

- [x] 首次路径只需 `setup` + `secret set` + `run`；不需要手写 JSON/Compose。
- [x] 错误信息包含 message/hint；不打印密钥或堆栈（除非 `COVE_DEBUG=1`）。
- [x] 密钥输入隐藏；支持 `--stdin` 自动化；`list` 不返回明文。
- [x] MCP add/list/remove 与 UI 同等能力；原始 TCP 明确拒绝。
- [x] UI 只绑定 127.0.0.1；写请求校验 Origin/Host/Sec-Fetch-Site + CSRF。
- [x] UI 不加载第三方脚本/字体；CSP 禁止 inline script。
- [x] 会话 ID 支持前缀解析；`down --all` 含 failed 状态。
- [x] 端口 7777 被占用时回退随机端口。

## 发现与处理

| ID | 发现 | 处理 |
| --- | --- | --- |
| U1 | `doctor` 复用了会创建 CA 的函数，产生副作用。 | 改用只读 `inspectCa`；验证空 home 不创建文件。 |
| U2 | `mcp list` 在 `map` 中使用 `await`，表格出现 Promise。 | 改为顺序循环。 |
| U3 | UI 的 `hidden` 属性被 `.modal-backdrop{display:grid}` 覆盖，首屏弹出密钥框。 | 增加 `.modal-backdrop[hidden]{display:none}`；截图复验。 |
| U4 | UI setup 会触发长时间镜像构建。 | `/api/setup` 传 `autoBuild:false`；UI 提示运行 `cove build`。 |
| U5 | 活动页只显示概览里的 20 条。 | 进入活动页单独请求 `/api/audit?limit=200`。 |
| U6 | `down` 只清理 running/starting，failed 残留不清。 | 加入 failed 状态。 |

## 验证

- `test/ui.test.ts`：CSRF 缺失返回 403；保存后 API/HTML 不含明文；MCP 409→带 Token 重试成功。
- 用 Edge headless 截图人工检查概览页布局、暗色对比、空状态、响应式断点。
- `cove --help`、`cove secret set --stdin`、`cove secret list`、`cove mcp list` 冒烟通过。
