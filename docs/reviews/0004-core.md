## 检查清单

- [x] DPAPI 通过 stdin 传明文、stdout 返回密文；密钥不出现在命令行参数。
- [x] vault 原子写；系统条目对用户列表隐藏；后端不匹配/密文损坏失败关闭。
- [x] CA 私钥只存 DPAPI；证书与私钥模数匹配校验。
- [x] 主机规范化拒绝 IP/本地名；通配符只匹配子域；路径按段前缀匹配。
- [x] 私网/环回地址检测覆盖常见 IPv4/IPv6 段。
- [x] 占位符泄漏检测与 403 决策在纯函数层可测。
- [x] DNS 只回答策略域名，未知域名返回 NXDOMAIN，不向上游转发。

## 发现与处理

| ID | 发现 | 处理 |
| --- | --- | --- |
| C1 | 通配符最初只匹配一级子域。 | 改为匹配任意深度子域，但排除 apex；测试固化。 |
| C2 | `Vault.set` 未传 hosts 时会清空已有 hosts。 | 改为继承已有 hosts；`remove` 禁止删除系统条目。 |
| C3 | CA 证书与私钥只校验格式，未校验是否配对。 | 增加 RSA 模数/指数比较，失败关闭。 |
| C4 | DNS `ANY` 类型在类型定义中不可用。 | 只回答 A；AAAA/其他类型返回 NOERROR 空答案，强制 IPv4。 |
| C5 | `inspectCa` 若复用 `loadOrCreateCa` 会让 `doctor` 产生副作用。 | 拆出只读检查函数，doctor 不再创建 CA。 |

## 验证

`pnpm test` 覆盖 vault、DPAPI（Windows）、CA、策略、注入、DNS、配置、网络与 preflight；全部通过。
DPAPI 测试包括 Unicode 往返与篡改密文失败。
