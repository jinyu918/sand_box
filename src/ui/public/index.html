LIFECYCLE

密钥如何流动

01录入

终端输入不回显，DPAPI CurrentUser 加密。

02占位

启动会话时生成随机占位符，写入沙箱配置。

03兑换

broker 只对授权主机替换 Header，记录脱敏审计。

04清理

容器删除，密钥不落沙箱磁盘，也不进日志。

MCP，不把 Token 带进沙箱

接入时只在本机输入一次。Claude Code、Codex、DSH 的配置自动生成，里面只有占位符。

读写写权限取决于你的 Token scope
NOT SUPPORTED IN v0.1

边界

PostgreSQL/MySQL 等原始 TCP MCP、需要 OAuth 登录的服务、证书固定客户端不在 v0.1 范围。 这些场景会在接入时明确拒绝，而不是悄悄降级。

每一次出网都有记录

只记录主机、方法、路径、状态与命中的凭据 ID；Header、Body、查询串和密钥不写审计。

本机设置

Cove 不提供远程访问。控制台只监听 127.0.0.1，所有写请求需要同源与 CSRF Token。
